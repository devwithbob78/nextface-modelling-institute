NEXTFACE MODELLING INSTITUTE — PHASE 1
======================================

What's included
- Responsive luxury black-and-gold landing website
- Custom text-based N/diamond brand mark
- Homepage, story, proposed programs, learning experience, steps and enquiry sections
- Mobile navigation
- Enquiry form demo (no data is stored or sent to a server)

HOW TO PREVIEW ON ANDROID
1. Download and extract nextface_phase1.zip.
2. Open the extracted folder in Acode (or another code editor).
3. Open index.html and choose Preview / Open in browser.
4. Keep index.html, styles.css and script.js in the same folder.

BEFORE PUBLISHING
1. Replace YOUR-ADMISSIONS-EMAIL@example.com in script.js with the real approved admissions email.
2. Confirm the legal business name, business address/contact details and social links.
3. Obtain permission to use all photography and replace image URLs with licensed/approved images.
4. Confirm curriculum, instructor credentials, age ranges, schedules and pricing.
5. Add approved Privacy Policy, Terms, accessibility information and child-safeguarding/parental-consent processes.
6. The current enquiry form is a front-end demo. It does not store submissions. A secure backend and verified guardian workflow are required before collecting real student or child data.
7. Do not collect payments yet. Stripe and the enrollment backend are later phases.

PHASE 1 STATUS
Frontend concept / prototype only. No student accounts, database, live classes, payment processing or admin dashboard are connected.

Image sources
The prototype references images hosted by Unsplash. Confirm each image's current license and usage suitability before commercial launch; use client-approved licensed imagery for production.
